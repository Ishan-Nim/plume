Installing

  1. Run the installer. Plume installs for everyone in C:\Program Files\Plume, so Windows asks for administrator approval once.
  2. The build is not code-signed yet. If SmartScreen says “Windows protected your PC”, choose More info → Run anyway.
  3. To open every .md file in Plume: right-click one → Open with → Choose another app → Plume → Always. Or use ⋯ → Make Plume the default for .md inside Plume.

Installing

  1. Open the DMG and drag Plume into Applications.
  2. Plume is not notarized by Apple yet, so the first launch is blocked. Right-click Plume → Open → Open. On macOS 15 and later, try it once, then go to System Settings → Privacy & Security and click Open Anyway.
  3. Still stuck? Run xattr -cr /Applications/Plume.app in Terminal.
  4. To make it the default: select a .md file in Finder → Get Info → Open with: Plume → Change All…

Installing

  • AppImage: chmod +x Plume-0.0.4-linux-x86_64.AppImage, then run it.
  • Debian or Ubuntu: sudo apt install ./Plume-0.0.4-linux-amd64.deb
  • On Ubuntu 24.04 and later, prefer the .deb — it installs the AppArmor profile Electron apps need to start there.
  • Set it as the default through Open With in your file manager.

Not code-signed yet. Windows SmartScreen and macOS Gatekeeper will both warn on first run, because signing certificates cost money that a free app does not make. Every build is produced in public by GitHub Actions straight from the tagged source, so you can check exactly what went into it.
