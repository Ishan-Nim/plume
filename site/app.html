Plume Vault

Your notes, on every machine.

100 MB of storage, free with an account, shared across every vault you link to it. Read them here, write them in Plume.

At least 10 characters, with a number or symbol.

Your documents are stored privately and are never shared or indexed. Plume has no telemetry.

How syncing works

  1. Open a folder in Plume and it stays a folder. A folder on your disk is never quietly made into a vault, and a loose folder can never sync.
  2. Create a vault when you want that folder to be one. Plume writes a .plume directory into it — an id, its own settings, an index of its files. A vault can stay on that one computer forever, and costs no storage.
  3. Link it to your account, one vault at a time. Linking is a deliberate act on a vault, not a setting on the account: signing in links nothing by itself.
  4. Clone it on the second computer — sign in there, pick the vault, and Plume downloads it. Or read it right here in your browser.

A linked vault takes one top-level folder of your account, named after the vault. Link as many as you like — vaults are not rationed. The 100 MB is bytes, drawn from one pool shared by all of them.

Unlinking a vault leaves both copies alone: the files stay on your disk and in your account, and no storage is freed. Deleting a vault from the account is the separate, destructive act that frees it.

Vaults need Plume 1.8 or later. Get the latest version.

    Using it with Claude Code

    Add this to your MCP settings, and Claude can keep project memory and notes in a vault on this account — readable from Plume on any machine that has cloned it. 

    {
  "mcpServers": {
    "plume-vault": {
      "command": "node",
      "args": ["/path/to/plume/mcp/index.js"],
      "env": { "PLUME_TOKEN": "your-token-here" }
    }
  }
}

    Clone the repository and point at mcp/index.js — the server has no dependencies to install.

    It gives the assistant eight tools: list, read, write, append, search and delete documents, plus the vault graph and its storage status.
