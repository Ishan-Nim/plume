How syncing works

  1. Create an account here, and confirm it with the code we email you. You get 100 MB.
  2. Open Plume on your computer and sign in under ⋯ → Plume Vault.
  3. Push a document to the vault from the toolbar, or turn on auto-sync so every save goes up.
  4. Open it anywhere — another computer running Plume, or right here in your browser.

Needs Plume 1.1 or later. Get the latest version.

    Using it with Claude Code

    Add this to your MCP settings, and Claude can keep project memory and notes in your vault — readable from Plume on any of your machines. 

    {
  "mcpServers": {
    "plume-vault": {
      "command": "node",
      "args": ["/path/to/plume/mcp/index.js"],
      "env": { "PLUME_TOKEN": "your-token-here" }
    }
  }
}

    Clone the repository and point at mcp/index.js — the server has no dependencies to install.

    It gives the assistant eight tools: list, read, write, append, search and delete documents, plus the vault graph and its storage status.
